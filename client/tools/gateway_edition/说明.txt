奥拉星现代内核客户端 网关版 v0.1.0-beta1（2026-11-08）

一、这是什么
  只有网关程序的轻量发行版：不含浏览器运行时（Ruffle/Chromium），使用你系统里的
  Node.js 与默认浏览器。与「整合包」（内嵌全部运行时，解压双击即玩）分开发布。

二、前置要求
  - 系统已安装 Node.js 18 或更高版本（https://nodejs.org 下载 LTS 版）
  - 一个现代浏览器（Edge / Chrome / Firefox 均可）

三、启动
  双击「启动网关.cmd」：
  - 网关以系统分配的可用端口启动（被占用自动回避，无需关心端口）
  - 启动完成会在窗口里显示游戏地址，并自动打开系统默认浏览器
  - 登录 → 选服 → 进入世界（全程免 Flash）
  关闭该窗口（或 Ctrl+C）即停止网关。

四、登录票据
  会话密钥短效：如果出现「插件不受支持」「登录失败」，双击「重打票据.cmd」后刷新页面即可。

五、端口与日志
  实际端口在启动窗口的横幅行：[serve] P0 mirror on http://127.0.0.1:端口/
  页面 socket 隧道代理地址自动跟随该端口，无需配置。

六、低配特效
  游戏页面左下角「⚙ 特效开关」面板（勾选即时生效），或直接编辑本目录 lowfx.json。

七、与整合包的区别
  | | 网关版（本包） | 整合包 |
  | 程序体量 | ~160MB | ~3.5GB（含浏览器运行时） |
  | 依赖 | 需自装 Node.js | 无 |
  | 浏览器 | 系统默认浏览器 | 内嵌 Chromium |
  | 启动 | 启动网关.cmd | 启动奥拉星.exe |
