# AolaSmartRefresh — 奥拉星My登录器 免登录智能刷新扩展

基于监控实测结论（渲染进程"地板"只涨不跌 → 2.6GB 峰值 → GC 空转）实现的伴生工具。
**原理**：CEF 加载本扩展后，游戏页面内的 content script 每 2 秒轮询本机代理；
代理发现内存超阈值（或你按 R）即下发 `reload` 指令 → 页面 `location.reload()`。
Cookie 会话持久保存在登录器配置目录里，**刷新后自动回到游戏，无需重新登录**。

## 文件

```
refresh-ext/
├── ext/manifest.json     CEF 扩展（MV2，无权限申请）
├── ext/content.js        页面内脚本：F5/Ctrl+R 拦截 + 轮询执行刷新
├── refresh_agent.ps1     伴生代理：HTTP 指令口 + 内存监控 + 控制台按键
└── README.md
```

## 安装（两步）

### ① 给启动器加扩展参数
右键"奥拉星My登录器"的**快捷方式** → 属性 → 在"目标"末尾追加（注意有个空格）：

```
 --load-extension=D:\temp\ZCode\aola\refresh-ext\ext
```

（若你是直接双击 exe 启动的，先创建一个快捷方式再改。）

### ② 启动伴生代理
双击运行，或在 PowerShell 里：

```
powershell -NoProfile -ExecutionPolicy Bypass -File D:\temp\ZCode\aola\refresh-ext\refresh_agent.ps1
```

> 首次安装想免按键验证链路：加 `-SelfTest` 参数启动，代理会在 3 秒后自动下发一次刷新——
> 若游戏页面随即自动重载（且无需登录），说明扩展+代理全链路已打通。

## 使用

| 按键 | 作用 |
|---|---|
| `R` | **立即刷新**（页面 2 秒内执行 reload，免登录） |
| `A` | 切换自动刷新（**默认关**：超阈值只蜂鸣提示，避免战斗中被误刷） |
| `S` | 查看状态（扩展是否连上 / 当前内存 / 上次刷新时间） |
| `Q` | 退出代理 |

自动逻辑：渲染侧最大子进程内存 **> 1800MB**（可调参数 `-ThresholdMB`）触发：
- 自动模式关（默认）：蜂鸣 + 日志提醒，按 `R` 手动刷
- 自动模式开（按 `A`）：直接下发刷新，冷却 300 秒防反复

## 验证安装是否成功（闭环）

1. 启动代理 → 启动登录器（带参数）→ 进入游戏页
2. 代理控制台/日志出现 **`EXT-ALIVE http://aola.100bt.com/...`** = 扩展已生效
3. 按 `R`，页面 2 秒内重载且**不再要求登录** = 全链路成功
4. 若 30 秒内无 `EXT-ALIVE`：说明该启动器未把 `--load-extension` 透传给 CEF —— 反馈给我，换 Plan B（包装器方案）

## 注意

- **战斗中刷新会退出当前战斗**，所以默认只提醒不自动刷；战斗结束后再按 R
- 刷新利用的是官方四级加载链 + 本地缓存，热重载约 30–60 秒回到场景
- 日志：`refresh-ext\agent_log.txt`
- 本工具只做"刷新"这一件事，不注入、不修改游戏客户端、不碰网络协议
